## 1. 迁移铁律

- **迁功能 = 迁完整玩法闭环**，不是只留一个按钮。  
  反例：星宝从「商店+背包+喂养+金币感」收成「−2⭐ 喂一下」→ Owner 反复追问。  
- 对照 `legacy.html` / `packages/web/legacy`：**商店、喂养、庆祝、BGM 切换、跟读** 在 2.0 必须有对等体验（经济可用认真星替代金币，但交互层次不能变浅）。
- 删减玩法必须先写规格并获 Owner 同意，禁止「先骨架以后再说」导致线上空壳。

## 2. 儿童产品非协商（视听交互）

面向 **3–8 岁**，下列是交付标准，不是 polish：

| 维度 | 最低要求 |
|------|----------|
| 图案 | 大表情/大按钮/高对比色块；忌信息密度仪表盘 |
| 交互 | 一步一反馈；可回退；关键步骤要有「开始」不能只有「完成」 |
| 声音 | TTS 可重播；BGM 切换后**真的在响**；答对/喂养有音效 |
| 动画 | 答对、喂养、升级、认养至少有可见动效 |

没有这些 → **不算完成**，即使 build 通过。

## 3. 音频血泪（BGM / TTS）

- BGM 是 **Web Audio 本机合成**，**不是下载资源**。别再问「是不是没下到本地」。
- 系统朗读（speechSynthesis）能响 ≠ AudioContext 已解锁。必须在用户手势内：`resume` + **静音 buffer kick**。
- 切 BGM 后立刻 TTS 会 duck；**TTS onend / 回前台 / 首次 pointerdown 必须 `ensureBgmPlaying()`**。
- **关闭音乐**：`wantedStyle=none` 时必须 `stop` 全部节点 + `bgmGain=0`；`duckBgm(false)` / TTS 结束不得把音量拉回。
- **切曲可辨**：八音盒慢高音正弦 / 童趣跳音叠五度 / 小游戏方波 / 轻快锯齿切分——验收时要听得出差异。
- 验收：家长角点曲目 → **应立刻听到循环旋律**（手机勿静音）。只听旁白不算过。关掉后旋律应停。
- Piper 可选、默认可 Web Speech；模型可 IndexedDB 缓存。Piper 失败必须静默回退，不挡课。

## 4. 课程 4 拍

- 每拍有「再听一遍」。
- **可回上一拍**（第 1 拍可回今日）。
- **说一说**：必须「开始说 → 录音+音量检测 → 停 → 可回放 → 通过才允许下一步」。禁止只有「我说完了」空点跳过。
- **想一想（收尾）**：用**疑问语气**提醒再读/再认（例：「这个字，读什么？」），并给一次选择判断；选项顺序勿与玩一玩完全相同。答对后再收认真星。禁止收尾直接说「你今天会认×」替孩子下结论。

## 5. 星宝经济与多宠

- 货币主线：**认真星**（上课获得）；旧金币可兑星。
- 玩法：认真星买食物 → 背包喂当前宠；可自选种类；**每小朋友独立**；最多 3 只；第 2/3 只认养更贵。
- 认养 / 切换 / 喂养 / 升级都要有声画反馈。
- **形态随等级**（宝宝→少年→成长→闪亮），**心情随饱食**；两条轴独立。升级可回落饱食到「还行」，禁止用饱食重置把高等级打回宝宝脸。

## 6. 工程约定（少折腾）

- 主代码只在 `packages/web`；根目录**不要**空壳 workspace `package.json`（单包阶段）。

- 宣称修过的 bug：**本机路径复测**，别只改代码写 PASS。
