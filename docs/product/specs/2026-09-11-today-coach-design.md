# 今日页情绪导读（Today Coach）

**日期：** 2026-09-11  
**状态：** approved（Owner 口述：样式+内容要改；进度/今日预期/小动物；情绪引导；点读）  
**范围：** `packages/web` 今日页顶部；不替代后续「日历 + 家长阶段统计」整包（另开 T）。

## 问题

原句「今天一起听一听、玩一玩。认真学习会得到认真星 ⭐」：

- 信息弱（课卡片已有 +⭐）
- 样式与课卡片同级，抢焦点、像可点块
- 无成长感、无今日目标、无星宝情绪连接

## 目标

今日顶部改为 **情绪导读条**（次于课列表的视觉权重）：

1. **鼓励进度**：会认字数 / 已完成课数（本孩本地数据）
2. **今日预期**：今日推荐课数 + 已完成几节 / 还差几节
3. **小动物状态**：当前星宝表情 + 一句话心情；无宠则温柔邀请去认养
4. **情绪引导**：短、具体、可停（完成则夸休息；未完成则加油不催）
5. **点读**：导读句支持「点字读音」+「听整段」

## 非目标（本条不做）

- 月历打卡、家长角分阶段报表（另规格）
- 改认真星经济规则

## 文案规则

- 用孩子名字；不出现分数/排名/羞耻
- 数字用阿拉伯数字便于点读识别
- 每日推荐课数 = 今日列表长度（当前最多 3）
- 星宝句用 `petMood` / 表情，与星宝页一致

## 验收

- [ ] 顶部不再是与课同级的空说明卡
- [ ] 可见：进度、今日预期、星宝状态（或邀请）
- [ ] 导读可点读；有「听整段」
- [ ] 完成今日全部推荐课后，语气变为「可以休息了」
- [ ] `npm run build` 通过
