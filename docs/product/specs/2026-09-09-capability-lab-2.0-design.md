## 0. 一句话定位

做一个**打开就能学、学了像在玩但不是在刷副本**的儿童能力培养站：按**科目 / 课程 / 能力 / 归属**模块化扩展；默认**无账号、本地进度、免费部署**；需要云同步时再挂**可选免费后端**，不绑死架构。

## 角色 A · 专业架构师 & 研发测试

### A1. 问题定义

AI 时代儿童能力不是「多装几个学科 App」，而是：

| 层 | 要解决什么 |
|----|------------|
| 知识 | 语数英等可迁移的基础符号与概念 |
| 认知 | 观察、分类、比较、规律、因果、空间 |
| 思维 | 试错、假设、计划、反思（元认知萌芽） |
| 表达 | 说、听、指认、简单叙述与创作 |
| 情感 | 安全依恋感、胜任感、好奇心（非焦虑卷） |
| 探索 | 主动点开、愿意再试、发现「我可以」 |

当前产品（1.1）已有：**识字闭环 + 思维五类 + 金币星宝 + 拟人语音**。缺口是：**能力模型未显式、科目未展开、课程/进度骨架弱、扩展靠堆函数**。

### A2. 能力体系（系统细化 · 产品北极星）

能力用 **「维度 × 年龄带 × 可观察行为」** 三维表，避免空喊「全面培养」。

#### A2.1 十大能力维度（一级）

1. **感知注意**：听辨、视辨、持续注意 3–8 分钟  
2. **观察发现**：找异同、细节、变化  
3. **分类比较**：按属性归类、异同比较  
4. **序列规律**：顺序、模式、简单预测  
5. **空间数量**：方位、多少、一一对应、10/20 以内（随年龄）  
6. **符号语言（语文）**：字词、听读、简单句、叙述  
7. **符号语言（英语）**：字母、听辨、常见词、跟说（非应试）  
8. **表达创作**：口述、指图说话、简单「做一道题给人看」  
9. **情绪社会**：等待、受挫后再试、轮流、鼓励他人（轻）  
10. **自主元认知**：选难度、知道「不会可以再听」、主动复习  

二级能力（实现时挂到关卡 `capabilityTags`）：

| 一级 | 二级示例（可扩展） |
|------|-------------------|
| 观察发现 | 找不同、找相同、找缺失、找变化 |
| 分类比较 | 二分类、多属性、排除法 |
| 序列规律 | ABAB、ABC、大小序、故事序 |
| 空间数量 | 上下左右、数数、比多少、合成分解 |
| 语文 | 识字、听音选字、跟读、组词萌芽、看图说句 |
| 英语 | 字母形音、听词指图、跟说单词、简单指令 |
| 表达创作 | 造句、讲一件事、选贴纸讲故事 |
| 情绪社会 | 安慰反馈、等待动画、合作（远期双人本地） |
| 自主元认知 | 自选关、错题再挑战、今日目标 |

年龄带建议：

| 带 | 年龄 | 交互原则 |
|----|------|----------|
| L0 | 3–4 | 大按钮、语音主导、少字、即时反馈 |
| L1 | 4–6 | 短关卡、可选听讲解、轻度选择 |
| L2 | 6–8 | 可有简单规则说明、短计划、表达变长 |

**反拔苗：** 同一能力有 L0→L2 路径；默认推荐「最近发展区」一档，禁止一次跳两档；无排行榜、无倒计时惩罚、无「你落后了」。

### A3. 模块化模型（扩展轴）

四条正交轴（任意内容卡片挂标签）：

```text
Subject（科目）     chinese | math | english | thinking | arts(远期)
Course（课程）      一组有序 Session，有目标能力与建议年龄带
Feature（功能）     listen | speak | choose | sort | classify | create | review | pet
Owner（归属）       system | family | child-created(远期)
```

内容单元建议 schema（JSON，可进 `packages/*/content/`）：

```json
{
  "id": "cn-lit-xing-01",
  "subject": "chinese",
  "courseId": "cn-basics-a",
  "ageBand": ["L0", "L1"],
  "capabilityTags": ["symbol.chinese.char", "listen.select", "observe"],
  "features": ["listen", "speak", "choose"],
  "owner": "system",
  "payload": { "char": "星", "pinyin": "xing", "emoji": "⭐" },
  "reward": { "coins": 2, "xpCapability": { "symbol.chinese.char": 1 } }
}
```

包/目录演进（在 1.2 多包之上）：

> **现行落地（2026-09-09 Owner）：** 不拆 `@kids/*` 多包；**`packages/web` 单项目**（Vite+React）+ 内嵌 `legacy/`。`packages/` 仅预留未来 `server` 等。模块边界用 `src/` 目录表达，而非独立 package。

```text
packages/
  web/            # 唯一当前项目（Vite + React + TS）
    src/          # 2.0 主应用
    legacy/       # 1.x ESM 单树
  # server/       # （未来预留，未建）
```

历史设想（未按此拆包，仅存档）：

```text
packages/
  core/           # 用户、存档、能力画像、路由壳
  subjects/ …
apps/web/         # 曾用路径，已迁入 packages/web
```

### A4. 技术与部署（简单 · 免费 · 可演进）

| 决策 | 建议 | 理由 |
|------|------|------|
| 运行形态 | **静态 Web/H5** | 部署简单、家长少折腾 |
| 开发框架 | **Vite + React（或 Preact）+ TS** | Owner 已允许引入合适框架；组件化对齐科目模块；比继续堆 vanilla 更利于 AI 协作 |
| UI | 自研儿童组件 + CSS 变量；可参考大按钮尺度（Code Quest / GCompris 思路） | 不过度游戏皮肤 |
| 路由 | 文件式或轻路由：`/today` `/subject/:id` `/course/:id` `/pet` | 清晰扩展 |
| 状态 | 本地优先：IndexedDB（进度/录音）+ localStorage（偏好） | 免费、可靠 |
| 部署 | **Cloudflare Pages 或 GitHub Pages**；`*.pages.dev` / `*.github.io` | 免费 HTTPS |
| CI | GitHub Actions：`npm run build` → Pages | 仍「一键推送」 |
| 后台（可选 Phase C） | **Cloudflare Workers + D1/KV** 或 **Supabase 免费档**（仅同步进度） | 默认关闭；无则纯本地 |
| AI | **默认不用云 API**；可选「家长自备 Key」的讲解；或本地 Web Speech | 符合少折腾、免账单 |

开源参考（借体验不硬 fork）：

- 识字节奏：hanzi-study  
- 思维活动类型：GCompris / Code Quest Kids  
- 积木创造（外链）：ScratchJr  
- 英语轻游戏：qlobe-kids  

**架构原则：** 内容 JSON 与引擎分离；科目包可独立上线；Feature 可跨科目复用（`choose`/`sort` 一次实现多科调用）。

### A5. 测试策略（研发测试视角）

| 层 | 做什么 |
|----|--------|
| 契约 | content schema 校验（CI） |
| 单元 | 能力标签结算、年龄带推荐 |
| 组件 | 大按钮可达、语音 duck、录音回放 |
| 旅程 | L0 打开→完成 1 课→喂星宝；L2 复习错题 |
| 无障碍/设备 | iPad Safari、Android Chrome、弱网 CDN |
| 反模式检测 | 单次 session 超时提示休息；禁止连错惩罚音过重 |

## 角色 B · 专业幼师（深度使用批判 + 优化）

### B1. 教育立场

- **目标：** 让孩子感到「我发现了」「我说出来了」，不是「我刷完了」。  
- **有趣但不赌徒化：** 允许星宝与金币，但**学习反馈本身要够甜**；奖励是点心不是主餐。  
- **自然进步：** 同一内容可听、可选、可说；错了是「再看一看」，不是失败结算。

### B2. 对当前软件（1.1）的问题清单

| 严重度 | 问题 | 教育影响 | 优化方向 |
|--------|------|----------|----------|
| P0 | 能力不可见：家长/孩子不知道「今天练了什么能力」 | 像散关卡 | 课后一句话：「今天练了观察和识字」+ 能力小星星（非分数卷） |
| P0 | 科目只有语文萌芽，数学英语空壳 | 无法「全面」 | 先上数感 L0、字母听辨 L0，各 1 条短课 |
| P0 | 关卡无「课程感」：缺引入—练习—表达—回顾 | 碎片 | 每课固定 4 拍：听→玩→说→回顾 |
| P1 | 四选一过多，表达/观察深度不够 | 偏应试选择 | 每课至少 1 个非选择互动（排序/分类/说一句） |
| P1 | 星宝与学习弱关联 | 易变成「为喂而刷」 | 喂养消耗「今日认真星」，认真星来自完成课而非纯点击 |
| P1 | 语音拟人了，但讲解策略单一 | 缺少支架 | 错两次后给「小提示」而非直接揭晓 |
| P2 | 年龄未分流 | 3 岁与 7 岁同入口 | 首次选「我几岁」或家长设年龄带 |
| P2 | 缺少「安静结束」 | 停不下来 | 今日目标 2–3 课满后温柔收束 + 休息建议 |
| P2 | 英语/数学若照搬识字题型 | 学科特点被抹平 | 数学重操作物；英语重听与指，少默写 |

### B3. 理想一节课（幼师脚本）

以语文课「星」为例（10–12 分钟）：

1. **引入（1′）**：「天上有什么会眨眼睛？」→ 图+语音  
2. **感知（2′）**：「星」大字、听读、指一指  
3. **辨析（3′）**：听音选字 / 找不同（观察）  
4. **表达（3′）**：看图说「我看见一颗星」（可录音回放）  
5. **回顾（1′）**：「你今天会认『星』，还练习了观察」→ +认真星 → 可选喂星宝  

数学课「比多少」：实物图拖一拖，不说「考试」。  
英语课「Aa / apple」：听→指→跟说，不写。

### B4. 情感与互动原则（优雅）

- 反馈：短、具体、可再试（已有拟人 TTS 方向保留）  
- 动效：庆祝轻、时长短（现有 celebrate 可保留）  
- 禁止：恐吓、羞耻文案、强社交攀比  
- 家长：默认旁观模式说明「陪坐比督学重要」

## 角色 C · 3–8 岁小朋友（使用体验）

> 口吻模拟孩子感受；用作验收「敢不敢兴趣 / 是否自然进步」。

### C1. 我会怎么用

- 「我想先摸那个会动的星星宠物。」  
- 「字太大我就喜欢；要是字很多我就不看。」  
- 「老师说话太像广播我会走神；像温柔姐姐我就愿意听。」  
- 「老是选 ABCD 我会腻；让我排排队、分一分更像玩。」  
- 「说错了要是骂我，我就不想打开了。」  
- 「如果突然很难，我会以为自己笨；如果一点点会了，我会自己再点。」

### C2. 好用吗 / 有没有兴趣

| 点 | 孩子感受目标 | 当前/风险 |
|----|--------------|-----------|
| 打开 | 3 秒进玩 | 用户选择还行 |
| 兴趣 | 「还想再来一关」但可停 | 星宝有吸引力；需防刷 |
| 难点 | 「有点难但能猜」 | 缺年龄带时 3 岁会挫败 |
| 趣味 | 发现与表达 > 升级数字 | 庆祝有了，课程故事感不足 |
| 成长感 | 「我会说这句了」 | 需回放自己的录音、看得见「会了的字」 |

### C3. 自然进步 vs 灌输

- **自然：** 我选了「再听一次」然后自己点对了。  
- **灌输：** 一上来就念定义、逼我写、倒计时。  
→ 产品必须把「再听 / 提示 / 跳过表达但保留听认」做成一等公民。

### C4. 小朋友验收句（可用作 QA）

1. 我不认字也能靠耳朵玩完一课吗？  
2. 我生气点错两次后，软件还温柔吗？  
3. 我能听到自己的声音吗？  
4. 玩完知道「我变厉害了一点点」吗（不是分数）？  
5. 我想停的时候，停得光荣吗？

## 统一产品蓝图（三视角合流）

### 信息架构

```text
今日（推荐 2–3 个短课，按年龄带）
  ├─ 语文
  ├─ 数学
  ├─ 英语
  ├─ 思维探索
  ├─ 我的表达（录音作品集）
  ├─ 星宝（认真星兑换）
  └─ 家长（年龄带、时长、导出本地进度）
```

### 路线图

| 阶段 | 交付 | 部署 |
|------|------|------|
| **2.0-A 骨架** | Vite+React+TS 迁移动线；能力标签 + 课程 4 拍引擎；今日页 | Pages 静态 |
| **2.0-B 三科 L0** | 语文课扩、数学数感 5 课、英语字母听辨 5 课 | 同左 |
| **2.0-C 深化** | 提示支架、作品集、认真星、休息收束 | IndexedDB |
| **2.0-D 可选云** | 家庭多设备同步（Workers/Supabase 免费档） | 仍可关 |

### 明确不做（防范围爆炸）

- 学科应试试卷、奥数、自然拼读完整体系一次做完  
- 强制账号、广告、内购  
- 依赖付费云 TTS/大模型才能打开  
- 重度联机对战、排行榜
