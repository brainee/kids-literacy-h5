# 星宝形态随等级成长

**日期：** 2026-09-16  
**状态：** approved（Owner：级别越高应更丰富好看；升完级又像归初始）  
**对照：** 常见养成（塔麻可吉 / 轻宝可梦）：**进化形态看等级**，**表情看饥饱**，两条轴独立。

## 问题

- `petFace(kind, hunger)` 只看饱食  
- 升级时 `hunger = 35` → 立刻回到「饿/初始」脸，等级成果看不见

## 设计

| 轴 | 驱动 | 表现 |
|----|------|------|
| 形态 stage | `level` | 宝宝→少年→成长→闪亮；主 emoji + 装饰 |
| 心情 mood | `hunger` | 文案 + 小表情角标，不覆盖主形态 |
| 升级反馈 | level+1 | 庆祝动效；饱食回落到「还行」档（约 55），避免刚升级就显饿 |

阶段（1-based level）：

- 1–2：宝宝  
- 3–4：少年  
- 5–6：成长  
- 7+：闪亮（光环/星星装饰）

## 非目标

- 自定义立绘资源包（仍用 emoji + CSS）  
- 饱食随时间衰减（可另开）

## 验收

- [ ] Lv1 与 Lv5+ 主视觉明显不同  
- [ ] 刚升级后仍是更高级形态，不是宝宝脸  
- [ ] 饿了只改心情文案/小角标，不把闪亮变回宝宝  
- [ ] build + smoke
