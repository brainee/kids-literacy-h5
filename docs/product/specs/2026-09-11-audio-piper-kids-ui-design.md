# 2.0-B 声音与儿童化成品

**日期：** 2026-09-11  
**状态：** approved（Owner：修 BGM/重播、儿童化、试用 Piper、测试+三角色验收出最终版）  
**范围：** `packages/web` 2.0 主应用

## 问题

1. 2.0 壳几乎无 BGM，家长无法切换；与 1.x 行为断裂。  
2. 发音进入拍后自动读，缺少稳定「重播」入口。  
3. UI 偏模板，不够儿童乐园感。  
4. Web Speech 听感机器；希望试 Piper，但默认仍 Web Speech，可手动/空闲下载，本地缓存。

## 决策

| 项 | 决定 |
|----|------|
| 默认 TTS | **Web Speech** |
| Piper | 可选增强：家长角「下载更甜嗓音」或空闲自动预取；**IndexedDB 缓存模型**（piper-plus 内置） |
| 未就绪 | 一律回退 Web Speech，不挡课 |
| BGM | 程序化 Web Audio（迁自 1.x）：关闭 / 八音盒 / 童趣 / 小游戏 / 轻快；切换即生效；播报时 duck |
| 重播 | 每拍固定「再听一遍」；点读保留 |
| 缓存 | 是：模型进 IndexedDB；设置偏好进 `kidsThinkLit.v2`（`ttsEngine` / `piperReady` 旁路） |
| 云 TTS | 不做 |

## 验收（三角色）

- **架构：** 无后端、可静态托管、引擎可切换可回退、模型可缓存。  
- **幼师：** 重播一键可达；点读仍在；音色可选但不强迫下载。  
- **儿童：** 大按钮、彩色乐园风、BGM 可开可关、点一下有声反馈。

## 非目标

数学/英语课包、删除 legacy、云 Key TTS。
