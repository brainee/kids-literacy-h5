**日期：** 2026-09-07  
**状态：** approved（Owner GO）

## 目标

以识字为载体，提升 3–7 岁儿童的**识别、观察、分类、排序、逻辑、表达**能力；内容丰富、孩子愿意玩；一期**纯前端、简单部署、免费资源、本地存储、安全稳定**。

## 非目标（一期）

云同步、付费字库、AI 口语评分、原生 App、数学/英语正式内容（仅预留入口）。

## 架构

- 单页静态应用：`index.html`（CSS/JS/数据内嵌），无构建、无后端。
- 持久化：`localStorage` 键 `kidsThinkLit.v1`。
- 语音：Web Speech API；BGM：Web Audio 程序化音轨（免外链依赖，离线可用）。
- 部署：本地打开 / Cloudflare Pages / GitHub Pages。

## 模块

1. 用户：预置星星、月月；可新增；数据隔离；欢迎语音。
2. 识字：字库（郑星辰礼乐优先 + 常用字）；读字 / 跟读录音 / 四选一 / 认识·不认识；level + 错题加权。
3. 思维乐园：观察、分类、排序、规律、表达（各多关）。
4. 复习测验：5/10/15；报告。
5. 设置：BGM 选择；微信兼容提示；科目占位（数学/英语即将开放）。
